# Requested refinements — prepared, not published

## Behaviour
- Manual task edit/delete stays immediate. Task Trash retention is now seven days (7x24h from deletion), with Restore and icon-only Delete from Trash. Delete from Trash removes that task's app restore entry immediately; original soft-deleted server data/backups are not physically erased. Other Trash types remain unchanged. Missing legacy deletion dates remain recoverable.
- Classes > Import classes has Copy class prompt. Paste ChatGPT JSON or use the existing text/image methods; preview rows remain editable/excludable. Required weekday/times/type cannot be guessed. Existing module/time/overlap/duplicate validation runs on Apply; no edits/removals of existing classes are inferred. Copy prompt does not send an AI request.
- High/normal/low priority appears as a red/yellow/green dot before the task name on Home/Plan/module lists, with accessible priority names and tooltips. Repeated priority text badges are removed from those rows; edit/delete/timer controls remain.
- Library has Import folder (supported browsers) and editable module suggestions from relative folder paths. Folder paths are displayed locally for review; files are uploaded through the existing private service and grouped by module, not stored as a nested folder tree. Unsupported/oversized folder files are excluded with a visible explanation. Up to 200 files / 500MB total per batch. Existing successful uploads are retained on failure and retries use the existing remaining-file flow.

## 50MB per file — backend activation pending
User selected 50MB per file. The UI/service supports this opt-in only when PLANNER_CONFIG.maxFileMB is 50, after applying and verifying the prepared supabase/004_file_limit_50mb.sql. Until then the default remains 10MB per file; folder totals can already exceed 10MB. No live config, bucket or database was changed.
The migration widens only the known file bytes check and existing private bucket file_size_limit; it aborts on unexpected configuration and never changes RLS/public access/credentials or deletes rows. Companion rollback refuses when larger metadata records exist; it never deletes them to force a downgrade. Do not rerun the legacy installation script after upgrading; its old exact-bucket-size assertion expects 10MB. Backups can parse files up to 50MB but the existing 50MB TOTAL file-content and 72MB JSON backup caps remain; large libraries need a separate backup strategy. NTULearn automatic PDF copying and PDF search retain their existing 10MB per-file limits. No claim of resumable large uploads or real 50MB cloud transfer verification.
