# Optional task times — local draft

Start/end are optional Singapore-local HH:mm values stored in existing per-task workspace metadata by database UUID. Untimed tasks retain their current date/duration. Start-only is accepted; a supplied end must be later on the same day and derives planned minutes. Actual study timer records stay separate. Invalid/overnight ranges do not save. Clearing time returns to flexible scheduling after the normal existing-task Inbox approval. Home/Plan/module rows show timed tasks chronologically before flexible rows; existing date filters, completion controls, edit/delete buttons and timers remain intact.
